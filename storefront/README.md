# KicksByDavid termékoldal script (HU + SK)

`kbd-pdp.js`: a termékoldal dizájnja és CRO-elemei egy fájlban. A `.sk` domainen szlovákul, máshol magyarul fut.

A fájlt az Unas nem a kódmezőből kapja, hanem jsDelivr CDN-ről tölti be, mindig egy adott commitra rögzítve:

    https://cdn.jsdelivr.net/gh/vazsan/kicksbydavid-price-service@<commit>/storefront/kbd-pdp.js

Frissítés: módosítsd a fájlt, commitold, és az Unas mezőben cseréld a `<commit>` részt az új commit azonosítójára.
